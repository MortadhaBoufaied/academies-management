CSV Schema Reference

Your CSV must contain the following columns. Use semicolons (;) or commas (,) as delimiters — both are auto‑detected.

Column Name Required Description Example
Question Required The user question or utterance What are the training hours?
Answer Required The chatbot's response Training is Mon–Fri, 16:00–18:00.
Category Optional Topic category for routing / analytics Training/Schedule
Source Optional Source document reference Academy Info

Example CSV

Question;Answer;Category;Source

How to register?;Visit our website or come to the office Mon-Sat 09:00-18:00.;Registration;Academy Info
