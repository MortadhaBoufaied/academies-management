Reusable Navigation Sidebar - Fixed left-side navigation (w-64 width) - Dynamic active menu highlighting based on `activeMenu` attribute - Links to all main sections - Footer info box  **Fragment Name:** `sidebar`  **Variables Used:** - `activeMenu` - Current active menu item (e.g., "users", "players", "admin")  ### 2. **navbar.html** - Reusable Top Navigation Bar - Sticky top header (ml-64 to account for sidebar) - Search bar - Notifications dropdown - Settings dropdown - User profile dropdown with logout  **Fragment Name:** `navbar`  **Variables Used:** - `pageTitle` - Title to display in navbar - `user.nom` - User's name (for profile button) - `user.email` - User's email (for profile dropdown) - `unreadCount` - Number of unread notifications  ### 3. **base.html** - Base Layout Template - Combines sidebar and navbar - Tailwind CSS configuration - Material Icons - Provides placeholder blocks for child pages - Script for dropdown menu handling  ## Usage Methods  ### Method 1: Using Thymeleaf Layout Dialect (Recommended)  This is the cleanest approach and requires the `thymeleaf-layout-dialect` dependency.  Add to your `pom.xml`: ```xml <dependency>     <groupId>nz.net.ultraq.thymeleaf</groupId>     <artifactId>thymeleaf-layout-dialect</artifactId>     <version>3.2.1</version> </dependency> ```  **Example Page:** ```html <!DOCTYPE html> <html xmlns:th="http://www.thymeleaf.org"        xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"        layout:decorate="pages/modules/layouts/base">  <head>   <title layout:title-pattern="$TITLE_INDEX">My Page | Football Academy</title> </head>  <body>   <th:block layout:fragment="pageContent">     <!-- Your page content goes here -->     <h1>Welcome to My Page</h1>   </th:block>    <th:block layout:fragment="pageScripts">     <!-- Page-specific scripts -->     <script>       console.log('Page loaded');     </script>   </th:block> </body> </html> ```  ### Method 2: Using Direct Fragment Replacement  If you can't use the layout dialect, use `th:replace`:  ```html <!DOCTYPE html> <html xmlns:th="http://www.thymeleaf.org"> <head>   <!-- Your head content --> </head> <body>   <!-- Include sidebar -->   <th:block th:replace="pages/modules/components/sidebar :: sidebar" />      <!-- Include navbar -->   <th:block th:replace="pages/modules/components/navbar :: navbar" />      <!-- Your page content -->   <main class="ml-64 p-8">     <!-- Content here -->   </main> </body> </html> ```  ## Passing Variables to Components  ### From Controller:  ```java @GetMapping("/users") public String users(@AuthenticationPrincipal UserPrincipal p, Model m) {     m.addAttribute("activeMenu", "users");     m.addAttribute("pageTitle", "Users Management");     m.addAttribute("user", p.getUser());     m.addAttribute("unreadCount", notificationService.countUnreadNotifications(p.getUser().getId()));     return "pages/modules/data-management/users/list"; } ```  ### In Your Template:  ```html <!-- The navbar will automatically use these variables --> <th:block layout:fragment="pageContent">   <!-- Your content here --> </th:block> ```  ## Dynamic Active Menu Highlighting  The sidebar uses `th:classappend` to highlight the active menu item:  ```html <a th:href="@{/admin/view/users}"     th:classappend="${activeMenu == 'users' ? ```  ## Complete Minimal Example  **Create a new file:** `pages/modules/admin/dashboard.html`  ```html <!DOCTYPE html> <html xmlns:th="http://www.thymeleaf.org"        xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"        layout:decorate="pages/modules/layouts/base">  <head>   <title layout:title-pattern="$TITLE_INDEX">Dashboard</title> </head>  <body>   <th:block layout:fragment="pageContent">     <div class="mb-8">       <h2 class="text-3xl font-bold" th:text="${pageTitle ?: 'Dashboard'}"></h2>       <p class="text-gray-600 mt-2">Welcome to the Football Academy Management System</p>     </div>          <!-- Your dashboard content here -->     <section class="bg-white rounded-lg p-6 shadow">       <h3 class="text-xl font-bold mb-4">Quick Stats</h3>       <!-- Stats cards, tables, charts, etc. -->     </section>   </th:block> </body> </html> ```  **Update your controller:** ```java @GetMapping("/admin/dashboard") public String dashboard(@AuthenticationPrincipal UserPrincipal p, Model m) {     m.addAttribute("activeMenu", "admin"); 'bg-primary-container text-on-primary-container font-bold' : ''}">   <span class="material-symbols-outlined">icon_name</span> New Page </a> ```  ## Key CSS Classes Used  - `w-64` - Sidebar width (256px) - `ml-64` - Left margin for main content (to account for sidebar) - `sticky top-0` - Navbar sticks to top on scroll - `fixed left-0 top-0` - Sidebar fixed position - `z-50` - Sidebar/navbar z-index - Tailwind color system: `bg-primary`, `text-on-primary`, etc.  ## Troubleshooting  1. **Sidebar not showing**: Check that the sidebar width class `w-64` is applied 2. **Content overlapping sidebar**: Ensure main content has `ml-64` class 3. **Dropdown not working**: Check that JavaScript for dropdowns is loaded 4. **Styles not applying**: Verify Tailwind CSS is included in the `<head>` 5. **Links not working**: Check that `th:href` URLs are correct and match your route mappings  ## Integration Checklist  -
