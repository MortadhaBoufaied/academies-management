3. HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Import in Your Screen
────────────────────────────────
import 'package:your_app/theme/app_colors.dart';

STEP 2: Use Theme Colors (Never Hardcode!)
────────────────────────────────────────────
✅ GOOD:
   color: AppColors.playerPrimary

❌ BAD:
   color: Color(0xFF009688)

STEP 3: Comment Your Screen's Theme
─────────────────────────────────────
/// PLAYER MANAGEMENT SCREEN THEME
/// Primary: Teal | Secondary: Blue | Accent: Green

STEP 4: Test Dark Mode
──────────────────────
Use AppColors.getBackgroundColor(isDark: isDark) for dynamic colors

5. SCREEN CONVERSION CHECKLIST
═══════════════════════════════════════════════════════════════════════════════

For each screen file:

   ☐ Add import: import 'package:your_app/theme/app_colors.dart';
   
   ☐ Add theme comment at top:
     /// SCREEN_NAME SCREEN THEME
     /// Primary: X | Secondary: Y | Accent: Z
   
   ☐ Replace all hardcoded colors:
     FROM: color: Color(0xFF009688)
     TO:   color: AppColors.playerPrimary
   
   ☐ Use semantic colors for status:
     FROM: status == 'paid' ? Colors.green : Colors.red
     TO:   status == 'paid' ? AppColors.paymentPaid : AppColors.paymentFailed
   
   ☐ Use helper methods for dark mode:
     FROM: isDark ? Color(0xFF1A2335) : Colors.white
     TO:   AppColors.getSurfaceColor(isDark: isDark)
   
   ☐ Test in both light and dark modes
   
   ☐ Verify all colors render correctly

6. QUICK START EXAMPLE
═══════════════════════════════════════════════════════════════════════════════

Before (Hardcoded colors):
─────────────────────────
class PlayerCard extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Container(
      color: Color(0xFFE8F5F3),
      child: Text(
        'Player',
        style: TextStyle(color: Color(0xFF009688)),
      ),
    );
  }
}

After (Using theme):
───────────────────
/// PLAYER MANAGEMENT SCREEN THEME
/// Primary: Teal | Secondary: Blue | Accent: Green
class PlayerCard extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Container(
      color: AppColors.playerCardBg,
      child: Text(
        'Player',
        style: TextStyle(color: AppColors.playerPrimary),
      ),
    );
  }
}
